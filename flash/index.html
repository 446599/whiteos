    怎么下载、导入？
    1. 打开 GitHub 发布页，展开版本下的 Assets。
    2. 下载 whiteos-X.Y.Z-full.bin（完整包）。不要选 whiteos.bin 或 Source code。旧版本没有完整包时，请使用在线烧录。
    3. 回到此页，点“选择完整包 .bin”。检查顶部显示的版本后，选择“固件更新”或“全新烧录”。

    已有 whiteos 选“固件更新”；首次安装选“全新烧录”。两个入口都能使用完整包。烧录请用电脑 Chrome 或 Edge 打开此页。
