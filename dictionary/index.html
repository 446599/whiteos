小纸 Pico / DICTIONARY

让词典，也来到小纸。

选一份词库，转换后传到设备。
全程在你的浏览器内完成，文件不会上传。

转换词典

也可以把文件拖到这里。StarDict 请一起选择同名的 .ifo、.idx、.dict 和可选的 .syn。

    支持 MDX、StarDict、CSV、JSON、TXT / TSV；每次转换一份词库，总文件大小不超过 128 MiB。

    转换完成

    下载 dictionary.pdict

    在小纸上打开「Wi-Fi 传书」，进入设备给出的地址，点「传词典」上传下载的文件。
    也可以复制到 TF 卡根目录的 DICT/dictionary.pdict。

    选文件时，看这里。

    MDX
    选择 .mdx。支持 MDX 1.x / 2.x 的未压缩和 zlib 文本词库；保留文字释义，去掉网页样式。MDD 中的图片和发音不导入。LZO、MDX 3 和需要注册密钥的词库暂不支持。
    StarDict
    一起选同名的 .ifo、.idx、.dict；支持 .idx.gz、.dict.dz 和 .syn。支持 2.4.2 / 3.0.0、32 / 64 位索引和 m/h/x 文本字段。
    CSV / JSON
    使用 UTF-8。CSV 为「词头、释义」两列；JSON 可用 {"hello":"你好"}，或 [{"word":"hello","definition":"你好"}]。
    TXT / TSV
    使用 UTF-8，每行「词头 + Tab + 释义」。Tab 是制表符；空格无法替代它。

    重复词头保留第一条；空释义及超过 127 字节的词头会跳过。超过 4095 字节的释义保留节选并标注。转换结果不超过 128 MiB，词库解压数据不超过 256 MiB。大型词库建议使用电脑浏览器。

    首次转换会下载约 13 MB 的本地转换引擎，请稍等。转换时可以切换标签页；关闭页面会中止转换。

    生成的索引词典需要支持 .pdict 的固件；已安装此前的词典优化固件即可使用。
