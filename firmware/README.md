# whiteos 1.0.0

首版固件，2026-10-09 发布，适用于小纸 Pico 4.7 英寸、ESP32-S3、16 MB Flash。

[下载完整固件包](./whiteos-1.0.0.zip) · [网页烧录](../flash/) · [发布清单](./manifest.json)

| 文件 | 用途 | 地址 |
| --- | --- | --- |
| bootloader.bin | 启动程序 | 0x00000 |
| partition-table.bin | 分区表 | 0x08000 |
| whiteos.bin | 应用，7,334,144 字节 | 0x10000 |

固件发布入口为 [GitHub Release v1.0.0](https://github.com/446599/whiteos/releases/tag/v1.0.0)。清单记录每份镜像的实际大小与 SHA-256，镜像内部版本为 1.0.0。Actions 在部署时校验 Release 附件并同步到 Pages 的版本目录；网页先校验完整发布包，再按清单写入，不读取或比对设备原有分区表。全新烧录使用三份镜像，固件更新仅使用应用；后续发布格式见 [说明](../RELEASE_FORMAT.md)。

ESP-IDF v6.1 编译、产品配置、内存布局、微信读书与 USB 链接检查、USB 主机生命周期回归和网站镜像校验通过。2026-10-09 已通过 Edge 网页完成真机应用更新，写入内容与保护区域校验通过并发送重启指令；重启后的屏幕与功能验收仍待确认。

固件包保留构建时的来源记录与第三方许可。包内“未公开发布”描述的是打包时状态；本仓库发布状态以本文为准。第三方许可见 [说明](./THIRD_PARTY_NOTICES.md) 和 licenses/，未将整个固件声明为单一许可证。
