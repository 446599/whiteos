# 外置每日一句

这是通用句库工具，不内置一言数据、不访问串口、不上传用户文件。只有点击下载才从固定的一言上游版本读取文学/原创数据；失败不会自动请求其他服务。JSON/TSV 文件在本机浏览器内处理。

网页公开显示：固件支持待发布，1.1.3 暂不支持。不修改正式发布的固件、清单或版本号。

句子包解压后，将 `QUOTES` 复制到 TF 卡根目录，安全弹出并返回主页。升级固件不自动导入句库。

- `daily.pquotes`：供设备有界读取。
- `source.json`：可编辑的数据，保留作者、出处和上游标识（如有）。
- `rebuild.mjs`、`core.mjs`：安装 Node.js 后执行 `node rebuild.mjs` 可重新生成设备文件。
- `README.txt`：来源、固定版本、修改时间和筛选说明。
- 一言包保留上游 `LICENSE.txt` 与 `UPSTREAM-README.md`。
- `coverage.json`：固定界面字体的码点覆盖事实表，不含字体笔画；重建时使用同一覆盖范围。
- `TOOL-LICENSE.txt`：独立转换工具的 MIT 许可；不覆盖句子的许可。

## 数据与授权

固定来源：https://github.com/hitokoto-osc/sentences-bundle/tree/07a74e13b572c2ad861d91f791788fd4253fc086

一言包是经筛选/去重/格式转换的数据，保留 AGPL-3.0 及可编辑来源，不宣称原文都是公共领域。部分引文版权归原作者。外置是一种数据组织方式，不是许可规避。发布该衍生句子包时须保留许可、来源、修改说明及对应可编辑数据，不另加限制。

自定义内容保留自己的授权；工具不替用户重新授权，也不核验每条文学摘录。示例是本项目编写的生活短句，不冒用名人署名。

## PQTS0001 格式

小端序，24 字节头：8 字节 ASCII `PQTS0001`、uint32 条数（1～4096）、uint32 记录长度（228）、uint32 保留值0、uint32 前20字节的 IEEE CRC32。

每条记录228字节：UTF-8 text[128]、credit[96]，均以NUL结束和补零；最后uint32为前224字节的IEEE CRC32。正文最多26个Unicode码点、署名最多32；拒绝控制符、非法UTF-8和双向文本控制符。工具筛选8～26字、默认最多1000条、去重并跳过界面字库未覆盖的文字，不擅改句子为其他名人署名。

设备只读取头和当前记录，校验计数、总长度、UTF-8、CRC及字符串边界；无整库加载、常驻文件句柄或网络请求。损坏/缺卡回退原创生活短句。
